# اتساق | ETSAQ
نموذج أولي ثابت (HTML/CSS/JS) لواجهات المنصة الذكية لحوكمة المناهج ومواءمة سوق العمل.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (مثلاً `etsaq-platform`).
2. ارفع ملفات `index.html` و`style.css` و`script.js` إلى جذر المستودع.
3. افتح Settings → Pages، واختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.
4. انتظر نشر الموقع ثم افتح الرابط الذي يظهر في صفحة Pages.

## تنبيه
هذه واجهة تجريبية عامة فقط، وليست نظامًا مؤسسيًا معتمدًا. لا ترفع ملفات المناهج غير المصرح بنشرها أو بيانات شخصية إلى مستودع عام. بيانات البرامج مفهرسة مبدئيًا من ملف توصيفات البرامج ويجب التحقق منها قبل الاستخدام الرسمي. المؤشرات التشغيلية غير الفعلية تظهر بعلامة —.
