# اتساق — الأقسام التدريبية (وحدة مستقلة)

التسلسل: الأقسام ← التخصصات ← معلومات التخصص ← المستويات الخمسة ← المقررات ← تفاصيل المقرر.

البيانات مستمدة من `catalog.json` المستخرج آليًا من الخطط التدريبية، وتحتاج تدقيقًا قبل اعتمادها. يتضمن 6 أقسام و10 تخصصات. الملف `academic_pages.json` **غير مضمن** حمايةً من نشر النصوص الكاملة بلا تصريح. يمكن استيراده محليًا لعرض صفحات مصدر التخصص داخل المتصفح فقط، دون رفعها لخادم.

للتشغيل المحلي: `python3 -m http.server 8000` ثم افتح المتصفح على `http://localhost:8000`.

للنشر: الملفات الأربعة في جذر مستودع مستقل أو مجلد فرعي بالموقع، بعد مراجعة حقوق النشر والبيانات. هذه الوحدة لا تتضمن تسجيل دخول أو قاعدة بيانات أو اعتمادًا للمراجعات الأكاديمية.
