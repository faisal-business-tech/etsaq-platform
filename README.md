# اتساق V10 — موقع عام بمحتوى فعلي
## الملفات للنشر في جذر مستودع GitHub Pages
index.html, style.css, script.js, catalog.js, README.md

## ماذا يعمل؟
- 6 أقسام، 10 برامج، 292 سجل مقرر مستخرج من الخطط.
- تفاصيل كل مقرر: الرمز، الاسم، المستوى، الساعات، المتطلبات، صفحة المصدر.
- بحث وتصفية في جميع المقررات.
- مراجعة أكاديمية ثمانية محاور، حفظ محلي في المتصفح وتصدير JSON.
- مؤشرات حقيقية مبنية على عدد السجلات، وإحصاءات المراجعات المحلية.

## حدود مهمة
- جميع بيانات الخطط مستخرجة آليًا ولم تُطابق بصريًا بالكامل مع المصدر.
- 292 «سجل مقرر» قد تشمل مقررات مشتركة/متكررة بين البرامج، وليست 292 مقررًا فريدًا.
- لا تتضمن الحزمة النصوص التفصيلية للوثائق أو ملفات المراجعين أو الشواهد.
- لا يوجد تسجيل دخول أو قاعدة بيانات مركزية؛ المراجعات على هذا الجهاز فقط.
- لا تستخدم هذا الموقع العام لتخزين معلومات سرية أو بيانات شخصية.
- لا يمكن استنتاج نسب المواءمة أو جودة المقررات دون مصادر وشواهد معتمدة.
